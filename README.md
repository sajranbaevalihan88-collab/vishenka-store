# Vishenka Store — система учёта магазина

Сайт на **React + Python (FastAPI) + PostgreSQL**. Все цены в **сомах (KGS)**.

## Запуск

Двойной клик по **`start.bat`** → откроется окно сервера (не закрывай его) → в браузере:

**http://localhost:8000/**

При первом запуске `run.py` сам создаст базу PostgreSQL `ademi`, таблицы, загрузит 41 товар из `Учет_товаров.ods` и соберёт React.

Вход в панель: кнопка **«Для продавца»** на сайте.

## Возможности

### Витрина
- Только товары со статусом «На витрине».
- Название, категория, количество, цена в сомах и фотографии.
- Каталог появляется сразу при выборе категории; поиск по названию и коду.

### Панель управления
- **Товары** — таблица как в твоей Excel: №, **Код**, Название, Категория, Закупка, Продажа, Кол-во, Наценка %, Сумма закупки, Сумма продажи, Фото, Статус.
  - Свой **код товара** задаётся вручную.
  - До 10 фотографий на товар, хранятся прямо в PostgreSQL.
  - Категория выбирается фильтром — список товаров обновляется сразу.
  - Новый товар сохраняется в черновики и не виден покупателям; кнопка «На витрину» публикует его.
- **Продажи** — поиск товара **по названию или коду**, остаток списывается автоматически.
- **Обзор** — статистика **за сегодня, вчера, неделю, месяц и всё время**: продано, выручка, затраты, прибыль, число сделок. Обновляется сразу после продажи. Плюс график по месяцам и список товаров, которые заканчиваются.
- **Отчёты** — автоматические отчёты по месяцам.
- **База данных** — резервная копия JSON (вместе с фото), восстановление, смена пароля.

Пароль нигде на экране не отображается.

## Где данные

| Что | Где |
|---|---|
| Товары, код, продажи, фото, пароль, категории | PostgreSQL, база `ademi` |
| Собранный фронтенд | `frontend/dist/` |

## Структура

```
start.bat          запуск
run.py             подготовка БД + сборка React + старт
config.py          настройки
db.py              схема и первичное заполнение
app.py             FastAPI API
seed_products.json 41 товар из Учет_товаров.ods
frontend/          исходники React (Vite)
uploads/           резервная папка (фото сейчас хранятся в БД)
```

Порт и подключение к PostgreSQL настраиваются в `config.py`.
