# Vishenka Store — витрина, POS-касса, сканер штрихкодов и Xprinter

Сайт и кассовая программа для бутика женской одежды на **React + Python (FastAPI) + PostgreSQL**. Все цены в **сомах (KGS)**.

## Запуск

Двойной клик по **`start.bat`** → откроется окно сервера (не закрывай его) → в браузере:

**http://localhost:8000/**

Вход в панель продавца и кассу: кнопка **«Для продавца»** на сайте.

## Новые возможности (POS-касса, сканер и Xprinter)

### 1. Беспроводной USB-сканер штрихкодов
- Вставьте USB-приёмник сканера в ноутбук — драйверы не нужны (режим клавиатуры HID).
- При сканировании этикетки товар **мгновенно отображается на экране** (с фото, ценой и остатком) и **сразу добавляется в чек** со звуковым сигналом.
- Работает даже при **русской раскладке клавиатуры Windows** и без установки курсора в поле поиска.
- Если отсканирован неизвестный штрихкод — система предложит сразу создать новый товар с этим штрихкодом.

### 2. Печать этикеток и чеков на Xprinter
- Каждому товару автоматически присваивается уникальный штрихкод **EAN-13** (или можно отсканировать заводской штрихкод с бирки).
- В разделе **«Товары и бирки»** кнопка **🏷️** открывает студию печати термоэтикеток для **Xprinter** (размеры **58×40 мм**, **58×30 мм**, **40×30 мм**, **30×20 мм** и лист **A4**), а также пакетную печать по остатку на складе.
- После оплаты чек можно распечатать на термоленте **Xprinter 58 мм или 80 мм**.

### 3. Удобная оплата (POS-касса)
- Мультитоварный чек (сканируйте сразу несколько вещей покупателя).
- Скидка на чек (`%` или в `сомах`).
- Способы оплаты: **Наличные** (с быстрыми купюрами и расчётом сдачи), **QR / Перевод (MBank / O!Деньги / Элсом)**, **Банковская карта** и **Смешанная оплата**.
- Вся аналитика в разделе **«Обзор»** автоматически показывает выручку по способам оплаты и чистую прибыль с учётом скидок.

### 4. Фирменный дизайн Vishenka Store
- Добавлен фирменный логотип **VS Vishenka Store** (шапка, hero-секция, витрина, окно входа, админ-панель и favicon).
- Оформление в фирменной палитре логотипа: глубокий винно-бордовый бархат, шампань-золото и тёплая светлая витрина для фотографий одежды.
- На витрине при нажатии на товар открывается галерея всех загруженных фотографий.
